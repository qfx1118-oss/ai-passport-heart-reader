# 心力阅读器：给朋友的安装包
下载可直接安装的版本：[Releases](https://github.com/qfx1118-oss/ai-passport-heart-reader/releases/latest)。下载完整 ZIP 并解压；GitHub 的 Source code ZIP 不含预编译固件，不能直接运行安装器。源码开发使用 source 目录，保留上游 FoloToy 与字体许可证。


这是运行在 FoloToy AI Passport 上的心力球录音精选阅读器。把整个 ZIP 解压到你的 Mac 上一个固定目录，再将同目录的 `AGENT.zh_CN.md` 交给你的 Agent（WorkBuddy、Codex 或其他能执行本机脚本和定时任务的 Agent）。不要只发送本文、单个固件或临时预览链接。

## 给 Agent 的一句话

请阅读这个安装包内的 AGENT.zh_CN.md，按说明为我的心力球和 AI Passport 完成安装、首次配网、心力球授权、内容提炼及定时更新；先确认我的设备身份和刷机数据影响，需要我登录或输入 Wi-Fi 时打开本机页面让我完成，其他步骤自动处理，最后报告实际验证结果。

## 准备条件

- macOS、Python 3.9或以上、联网、支持数据传输的USB线、FoloToy AI Passport ESP32-C3 8MB。
- 你自己的心力球账号及可用的心力球 MCP。使用官方页面授权，不复制别人的账号或凭证。
- Mac 与 AI Passport 接入同一可信局域网，设备使用2.4GHz Wi-Fi；访客隔离可能阻断连接。
- 安装包解压目录不要删除或移动：后台服务使用这里创建的 Python 环境。

当前安装器只支持 macOS。Windows/Linux需要另行适配，不保证双击即用。不需要自己编译固件或安装 ESP-IDF，准备阶段会下载开源 Python 依赖。

## 功能与定时规则

上/下切换，确认键暂停/恢复，自动每10秒轮播；顶部显示日期、时钟、农历、成都锦江区附近天气。七格显示本期积累天数，不显示倒计时。

工作日09:25提炼，09:35服务开放，设备每60秒拉取。周二取周一，周三取周一至周二，周四取周一至周三，周五取周一至周四；周一取完整上周一至周日。周末、法定假日不更新；周一放假则首个工作日先补上周，下一个工作日开始本周累积。空内容/失败保留旧期。

Mac需醒着、Agent任务能运行、心力球授权有效并有可用模型额度。无需额外付费云服务器，但仍消耗你自己Agent的模型额度，不保证Mac休眠或退出Agent后定时任务仍执行。天气固定为锦江区；换城市要另行修改并重新验收，不属于本包的首次配置步骤。

## 安装包内容与隐私

- `firmware/full.bin`：分享版完整固件，从0x0刷入；首次全新安装可能覆盖原分区和Wi-Fi等设置。
- `firmware/application.bin`、`bootloader.bin`、`partition-table.bin`：供已核对分区兼容的保留设置安装。
- `install.py`：校验、依赖准备、指定设备刷入、中转安装与打开配网页面。
- `tools/`：原有提炼发布和中转工具的便携版。
- `source/`：同版应用源码、板级组件、构建配置与字体，供后续开发；不含私有内置内容。首次安装无需编译，开发需另配ESP-IDF 5.5.3。
- `SHA256.json`：逐文件校验。能发现损坏，不能替代可信来源验证。
- `licenses/`：上游项目与字体许可证；安装的依赖保留其发行许可证。

固件默认无私人句子，首次开机显示待同步。包内不含原用户的录音、心力精选、设备绑定、Wi-Fi、密钥、OAuth凭证或ELF调试文件。每个朋友首次配置时创建自己的密钥，只在本机保存。局域网HTTP不加密，只在可信网络使用。

## 需要本人确认的步骤

Agent先运行 `python3 install.py --prepare` 和 `python3 install.py --devices`。通过拔插确定AI Passport，不能选第一个ESP32。经你批准才刷机；保留设置模式会检查分区兼容性，不兼容会停止。若同意替换原系统及设置，才使用明确的全新安装选项。无需备份旧固件才能安装，但这不代表旧数据被保留，也不提供原厂固件自动回退。

配网页面是 `http://127.0.0.1:8765/setup`，Wi-Fi密码只由你在本机输入。心力球授权同样由你在官方页面完成。Agent会核验服务与首次真实内容，再创建唯一的定时任务，不要求把整个录音库送入模型上下文。

## 卸载和验证范围

停止Agent中本任务；从解压目录用 `.venv/bin/python tools/install_mac_bridge.py --uninstall` 移除登录服务。内容文件保留，固件不会自动恢复原厂。不要误删其他服务。

同功能基础版本曾通过原设备显示/按键验收；本包去掉私人内置内容后的准确固件需在你的设备上首次验收。构建与主机检查结果见 `firmware/build-info.json`，不把编译或安装成功当作实体屏验收。
